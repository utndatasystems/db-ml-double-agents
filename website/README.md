# Website

This directory contains the static DB ↔ ML Crossovers frontend.

## Files

```text
website/
├─ index.html
├─ assets/
│  ├─ app.js
│  └─ styles.css
└─ data/
   ├─ site_data.js
   └─ site_data.json
```

The site is intentionally framework-free: plain HTML, CSS, and JavaScript.

`data/site_data.js` and `data/site_data.json` are generated by `../scripts/build_site_data.py`. Do not hand-edit them.

From the repository root, rebuild and preview with:

```powershell
.\run_website.bat
```

or rebuild only:

```powershell
python .\scripts\build_site_data.py
```

The public UI only presents results (researchers, venue crossovers, service records, and ML publications). Pipeline and identity-resolution details remain in the data scripts and are not presented as a methodology section in the frontend.

## Extension pattern

When new data becomes available:

1. add/derive it in the pipeline;
2. expose it in `scripts/build_site_data.py`;
3. render it in `assets/app.js` if it is useful to visitors.

Keeping this boundary makes the site easy to maintain and allows the underlying entity resolution to improve without redesigning the frontend.
